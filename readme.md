# Gestion des Tâches

Mini-projet en Python permettant de gérer une liste de tâches dans le terminal.

## Fonctionnalités
- **Ajouter une tâche** (avec vérification que le titre n'est pas vide)
- **Afficher** toutes les tâches enregistrées
- **Rechercher** si une tâche existe dans la liste
- **Quitter** le programme

## Étapes réalisées
1. Création d'une liste vide `ls` pour stocker les tâches.
2. Ajout d'une boucle `while` pour afficher le menu en continu tant que le choix est différent de `0`.
3. Utilisation des conditions `if / elif / else` pour exécuter l'action choisie par l'utilisateur (ajouter, afficher, rechercher).

## Exécution dans VS Code
1. Ouvrir le fichier `.py` dans **VS Code**.
2. Cliquer sur le bouton **Run Python File** (l'icône de lecture  en haut à droite).
3. Utiliser le menu qui s'affiche dans le terminal en bas.
